Django Etsy Clone — Marketplace Platform

Django Etsy Clone is a marketplace web application inspired by the core structure of Etsy.

The project provides users with authentication, product categories, product search, detailed product pages, and administrative management.

Purpose

The project was developed as a practical Django marketplace project to understand how an online marketplace can be structured and managed.

Features

- User Registration
- User Login
- User Logout
- Product Categories
- Product Search
- Product Detail Pages
- Comment section
- Product Management
- Django Admin Panel


Product Discovery

Users can browse products through categories and search for specific products using the search functionality.

Each product has its own detail page where users can view detailed information.

Authentication

The project includes:

- Registration
- Login
- Logout

This allows users to create and manage their accounts.

Administration

Products and other platform data can be managed through Django Admin.
